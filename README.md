# MuayVerse — Backend & Model

API และโมเดลประเมินท่ามวยไทย รับวิดีโอจากแอป สกัดท่าทาง เปรียบเทียบกับท่าต้นแบบ
แล้วส่งคะแนนความคล้ายพร้อมคำแนะนำแก้ท่ากลับไป

โครงการนี้ได้รับทุนสนับสนุนจาก สวทช. และ วช. ในการแข่งขันพัฒนาโปรแกรมคอมพิวเตอร์แห่งประเทศไทย
ครั้งที่ 27 (NSC 2025)

> ส่วนนี้คือฝั่งเซิร์ฟเวอร์ — แอปมือถืออยู่ที่ [MuayVerse_Frontend](https://github.com/funkapu/MuayVerse_Frontend)

## วิธีการ

### ชุดข้อมูล

ไม่มีชุดข้อมูลท่ามวยไทยที่ใช้งานได้อยู่ก่อน จึงเก็บข้อมูลท่ามวยจากครูมวยไทยในพื้นที่เอง
เพื่อใช้เป็นท่าต้นแบบ

### ปัญหาเรื่องสัดส่วนร่างกาย

ผู้ฝึกแต่ละคนมีความสูงและสัดส่วนต่างกัน ถ้าเปรียบเทียบพิกัดข้อต่อตรง ๆ ระบบจะตัดสินจาก
**ขนาดตัว** แทนที่จะตัดสินจาก **ท่าทาง** คนตัวเล็กที่ทำท่าถูกจะได้คะแนนต่ำกว่าคนตัวใหญ่
ที่ทำท่าผิด

แก้ด้วยการทำ normalization ปรับสัดส่วนร่างกายให้อยู่บนมาตรฐานเดียวกันก่อนเปรียบเทียบ

### การให้คะแนน

ใช้ **Siamese network** ซึ่งเรียนรู้ที่จะวัดความคล้ายระหว่างท่าสองท่า แทนที่จะจำแนกว่า
เป็นท่าอะไร ข้อดีคือเพิ่มท่าใหม่ได้โดยไม่ต้องเทรนโมเดลใหม่ เพียงเพิ่มท่าต้นแบบเข้าไป

ผลลัพธ์ออกมาเป็นเปอร์เซ็นต์ความคล้ายกับท่าต้นแบบ

### คำแนะนำแก้ท่า

ส่งผลการเปรียบเทียบเข้าโมเดลภาษาเพื่อแปลงตัวเลขให้เป็นคำแนะนำที่ผู้ฝึกเข้าใจได้ทันที

## ทำไมเลือก TensorFlow

เพราะต้องการให้โมเดลมีขนาดเล็กพอที่จะย้ายไปทำงานบนโทรศัพท์มือถือได้ในภายหลัง
ไม่ต้องพึ่งการเชื่อมต่อเซิร์ฟเวอร์ตลอดเวลา

## ติดตั้ง

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

**สร้างไฟล์ `.env`**

```
FIREBASE_CREDENTIALS=<path ไปยัง service account json>
GOOGLE_CLIENT_ID=<Google OAuth client id>
LLM_API_KEY=<API key ของโมเดลภาษา>
```

**รัน**

```bash
uvicorn main:app --reload
```

เปิด `http://localhost:8000/docs` เพื่อดูเอกสาร API แบบโต้ตอบได้

## ข้อจำกัด

- ท่าต้นแบบครอบคลุมเฉพาะท่าที่เก็บข้อมูลมาแล้ว ท่าที่ไม่มีในชุดข้อมูลประเมินไม่ได้
- ประเมินจากวิดีโอมุมเดียว ท่าที่มีการบังกันของแขนขาอาจให้ผลคลาดเคลื่อน
- ยังไม่ได้ประเมินความแม่นยำเทียบกับการให้คะแนนโดยครูมวยอย่างเป็นระบบ
